AccessRig

A one-command installer/updater for JumpServer on a fresh EC2 box.
By Yousaf Hamza

JumpServer is built and maintained by Fit2Cloud and the JumpServer open-source project. AccessRig is an independent deployment wrapper — it does not modify or redistribute JumpServer's code.

Install

curl -fsSL https://yousafkhamza.github.io/accessrig/install.sh | sudo bash -s -- \
  --org-name "Pay10" \
  --s3-bucket "jumpserver-recordings-prod" \
  --s3-region "eu-central-1" \
  --timezone "Asia/Dubai" \
  --language "en"

Update (safe, in place)

curl -fsSL https://yousafkhamza.github.io/accessrig/install.sh | sudo bash

Auto-detects an existing install, backs up /opt/jumpserver, and upgrades in place.
